## 計算ロジック

- 広告徒歩`min..max`分→概算道路距離`80×(min-1) < d ≤ 80×max`m。
- 経路距離が区間内か外か、外なら何mずれるかを計算し、両端の道路への吸着量も並べる。
- 吸着が25mを超えれば`review_snap`。同一駅の2候補が80m以上異なる場合は`ambiguous_station_representatives`。
- 出典・道路グラフの版、駅出口、建物入口が未検証なので、**参考区間内**は物件一致を証明しない、**参考区間外**は広告違反や物件除外を意味しない。
- ユーザーは計算画面で広告徒歩分数を変えられる（実測の道路距離値は固定）。`この経路だけ再取得`ボタンを押した時だけ1経路をValhallaへGETリクエストし、polyline6を復号して始点・終点の吸着量を測る。
- GitHub Pagesは未公開。**ブラウザから外部ValhallaへのCORSアクセス実機確認は未完了**。接続失敗の場合は保存済みの9件を維持。アクセス先は固定の公開デモAPI、X-Client-Idを送る。APIに対してバルクアクセスや自動連続更新をしない。公開配布する際はプロバイダーへの事前連絡・専用APIへ移行。
- 地図上での候補建物生成、任意の広告URL取得、実際の個別住戸の住所推定・公開は実装していない。
