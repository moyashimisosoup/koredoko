# APP-023｜街区代表点のオフライン照合経路（2026-10-21）

**段階：ISJ_OFFLINE_IMPORT_IMPLEMENTED / 実データ未投入 / 新規経路0本**

## 判断と理由

GSI地名検索APIは手動照会として試行したが、このセッションからの直接応答を取得できなかった。国土地理院の公式開発者回答でも、地理院地図内部で主に利用する機能であり、継続提供や仕様固定が保証されていない。[公式Issue](https://github.com/gsi-cyberjapan/gsimaps/issues/29)。

これに依存せず、国土交通省が正式に頒布する**街区レベル位置参照情報（ISJ）**をオフラインCSVから取り込む経路を追加する。これは住所と街区（○丁目○番）の代表緯度経度を結び付ける静的データであり、道路アクセス点ではない。

一次資料：
- [国土交通省：位置参照情報の概要](https://nlftp.mlit.go.jp/isj/)
- [街区レベルCSV仕様（Shift-JIS・座標・履歴フラグ）](https://nlftp.mlit.go.jp/isj/data.html)
- [データの入手](https://nlftp.mlit.go.jp/cgi-bin/isj/dls/_choose_method.cgi)
- [ダウンロードサービス利用約款とデータ利用約款](https://nlftp.mlit.go.jp/isj/agreement.html)

**利用者は公式約款を読み、同意したうえで公式ダウンロードサービスからファイルを取得すること。** 今回自動ダウンロードや約款同意の代行は行わない。データの転載・引用時は「街区レベル位置参照情報 国土交通省」の出典、整備年度、元ファイル名、加工責任者等を記録する。公共測量や真の入口座標の証明には使用しない。

## 保存したプログラム

- [`src/hibari_offline_isj_match.mjs`](../src/hibari_offline_isj_match.mjs)：
  - Shift-JISデコード済みCSVの読込、引用符・カンマ・改行・エスケープ引用符の解釈。
  - 「東京都西東京市」「大字・町丁目」「街区符号・地番」を正規化して、**市・町・丁目・番がすべて一致する街区だけ**を候補にする。
  - 漢数字と全角数字の正規化。別街区、削除扱いの履歴行、欠損や不正座標は不採用。
  - 街区に複数参照点があるときは候補を隠さず、代表フラグに沿って扱う。
  - **街区代表点を建物入口・公園入口・駅出口に昇格させない**。
- [`scripts/hibari_isj_offline_review.mjs`](../scripts/hibari_isj_offline_review.mjs)：CSVファイルを引数として受け取り、ネットワーク通信を行わず照合結果をJSONで出力。版の年度・ファイル名・SHA-256を出力し、追跡可能にする。
- [`tests/hibari_offline_isj_match.test.mjs`](../tests/hibari_offline_isj_match.test.mjs)：**合成CSV**で正規化、異なる街区、削除履歴、複数候補、欠測、出典必須を回帰検査。
- 既存の[`hibari_reference_point_plan.mjs`](../src/hibari_reference_point_plan.mjs)も修正。GSIの返答に「西東京市」があるだけでは採用せず、入力住所と**同じ町・丁目・街区**であることを必須にした。番が異なる場合は採点素材にしない。

## 実行例（Node 20/24）

```bash
# MLIT公式配布ファイルを本人が規約確認後にダウンロード・展開
node scripts/hibari_isj_offline_review.mjs path/to/tokyo_block.csv 2025 > hibari_isj_review.json
```

※`2025`は例。実際の整備年度を使用し、混同しない。CSVはShift-JISであり、テスト用合成ファイルとは区別する。**元CSVは本Publicリポジトリに複製しない**。必要最低限の街区代表点を出典付きで結果へ採用する場合も、公式利用条件と精度注記を維持する。

## 計測・採点の出口条件

1. ISJ公式ファイル（または別の一次ソース）の実データと更新年度を取得して、候補7棟・駅1・施設5の住所について街区参照点の一致度と欠測を集計。
2. 街区代表点と出入口の差を、現地写真／公式建物・施設地図／国土地理院航空写真など別の資料で分類。特に学校の校門・公園ゲート・広いマンション敷地で要注意。
3. 現実の経路エンジンから歩行観測を少量ずつ取得し、端点スナップ距離、時刻、経路グラフの版固定可否を保存する。経路が未取得なら保留。
4. 本人・住戸の所在地を特定する出力は対象外。広告入力・公開候補の位置台帳・正解照合を別ファイルに保ったまま、駅のみ対施設併用の参考Top1/Top3・保留率を比較する。
5. 実広告H01〜H07と既存53経路・採点重みは不変のまま。どの段階でも**精度向上未確認の状態を変更しない**。
