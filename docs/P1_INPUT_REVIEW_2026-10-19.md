# APP-023 koredoko｜P1 入力MVP 初稿

日付：2026-10-19 JST / 対象ブランチ：`work/p1-input-review-20261019`

## 目的

公開不動産広告のURLから自動取得する前段階として、AIが抽出した定型JSONを**外部送信せずに検査**し、情報源・原文引用・不明値・徒歩条件を安全に取り扱う。ユーザーがスマートフォンで操作できる小さなWeb画面を初期提供する。

## 実装した範囲

- `index.html` に物件URL記録欄、広告原文（任意）、schema v0.2のJSON貼付欄、架空サンプル読み込み、AI抽出指示のコピー、入力消去、結果の問題表示。
- `src/input_review.mjs` は副作用を持たないブラウザ内の簡易入力点検器。出典IDの重複、徒歩分数範囲、根拠の参照先、広告原文引用の存在、施設固有名がない場合の注意を調べる。
- テキストの画面表示はDOMの`textContent`だけで行い、利用者の広告文をHTMLとして実行しない。
- JSONの基本点検に合格しても、現実の広告内容・建物位置・情報源の独立性を確定しない。
- ユーザー入力は外部APIに送信せず、ブラウザのlocalStorageにも保持しない。サンプルJSONのみ同一オリジンから取得する。

## 未実装・未検証

- HTMLや広告本文のテキストから直接構造化する自動抽出機能。URLは取得せず単なる参照欄。
- 完全なDraft 2020-12 JSON Schema検証は既存のPython tests/test_contracts.pyに残し、ブラウザ側はチェック項目を限定している。Pythonスキーマとブラウザの細部の判定が一致する保証はない。
- 引用文が原文に含まれることと、その記述が真実であることは違う。AI生成JSONの正確性は未検証。
- GitHub Pages公開、PCブラウザでの実操作、iPhone Safariによる操作性テスト、色・コントラストを含むアクセシビリティ検収は未実施。
- 実在する個人宅や居住者の非公開所在地を特定したり公開したりすることを目的としない。
